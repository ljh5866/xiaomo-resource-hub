## 一、做了什么

| 页面 | 能力 |
|---|---|
| `/admin` | 概览：已发布数 / 本周更新 / 死链率 / 索引条数 + 三个快捷入口 + 最近更新表 |
| `/admin/resources` | 资源列表：状态筛选（全部/已发布/草稿/已归档）、行内发布/下线、删除、点标题进编辑 |
| `/admin/resources/new` | 新建：基本信息 / 分类与属性 / 多链接 / 标签与来源 / 发布与 SEO，五段式 |
| `/admin/resources/[id]` | 编辑：同上，预填现有数据，右上角「看前台」 |
| `/admin/imports` | 批量导入：粘 CSV → 解析 → 入库，逐行报错（slug 重复、分类不存在、链接格式） |
| `/admin/links` | 链接巡检：按状态排序（失效最前）、失败次数、最近检测时间、错误原因 |

命令行：

```bash
pnpm links:check          # 巡检一轮（连续失败 3 次判死）
pnpm links:check --dry    # 只看结果不写库
pnpm db:reindex           # 重建搜索索引
```

| 设计 | 行为 |

## 三、两个踩过的坑（新项目必看）

### 1. `node:sqlite` 返回 null-prototype 对象，不能传给 Client Component

报错：

```
Only plain objects, and a few built-ins, can be passed to Client Components
from Server Components. Classes or null prototypes are not supported.
```

`DatabaseSync.prepare().all()` 返回的是 `[Object: null prototype]`。
修法：在 `src/db/client.ts` 的 `all()` / `get()` 出口统一 `{ ...row }` 转普通对象。**一处修，全局好。**

### 2. `"use server"` 文件只能导出 async 函数

```
A "use server" file can only export async functions, found string.
```

`actions.ts` 里顺手写的 `export const CSV_EXAMPLE = ...` 直接让构建失败。
常量要么放回组件，要么另开一个不带 `"use server"` 的模块。
