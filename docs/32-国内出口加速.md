# 32 · 给服务器配国内出口（加速夸克解析与下载）

> 现状：香港机器到夸克 TLS 握手 **3–6 秒**、下载单连接 ~115 KB/s。
> 配一台国内跳板后，解析 TTFB 可从 6s 降到 0.2–0.5s，下载吞吐也能翻上去。

## 需要什么

| 项 | 说明 |
|---|---|
| 一台国内机器 | 任意云厂商轻量即可（1C1G 够），**不需要备案**（只跑代理端口，不做网站） |
| 一个代理端口 | 例如 `8888`，只需要香港机器能连 |
| 别开公网 | 安全组只放行香港机器 IP `43.103.48.5` |

## 一、国内机器：装代理

用 gost（单文件、无依赖）：

```bash
curl -L https://github.com/go-gost/gost/releases/latest/download/gost_3.0.0_linux_amd64.tar.gz | tar xz && sudo mv gost /usr/local/bin/ && gost -V
```

带账号密码启动（把 `账号` `密码` 换成自己的）：

```bash
sudo tee /etc/systemd/system/gost.service >/dev/null <<'EOF'
[Unit]
Description=gost http proxy
After=network.target

[Service]
ExecStart=/usr/local/bin/gost -L http://账号:密码@:8888
Restart=always
RestartSec=3

[Install]
WantedBy=multi-user.target
EOF
sudo systemctl daemon-reload && sudo systemctl enable --now gost && systemctl status gost --no-pager | head -5
```

安全组：放行 `8888`，来源填香港机器 `43.103.48.5/32`。

自测（在国内机器上）：

```bash
curl -x http://账号:密码@127.0.0.1:8888 -s -o /dev/null -w "via-proxy=%{http_code} t=%{time_total}\n" "https://uop.quark.cn/cas/ajax/getTokenForQrcodeLogin?client_id=532&v=1.2&request_id=t"
```

## 二、香港机器：让站点走代理

`.env` 追加一行（**只走 curl**，不改 Node 全局代理设置）：

```bash
sudo sed -i '/^HTTPS_PROXY=/d;/^https_proxy=/d' /var/www/xiaomo/.env && echo 'HTTPS_PROXY=http://账号:密码@国内机器IP:8888' | sudo tee -a /var/www/xiaomo/.env >/dev/null && sudo systemctl restart xiaomo && echo PROXY_OK
```

代码侧已经做好：`src/lib/pan/http.ts` 检测到 `HTTPS_PROXY` 就**优先用 curl**（curl 原生读该变量），
所以不需要给 systemd 加 `NODE_USE_ENV_PROXY`。

## 三、验证

```bash
sudo systemctl show xiaomo -p Environment | tr ' ' '\n' | grep -i proxy ; curl -x "$(sudo grep '^HTTPS_PROXY=' /var/www/xiaomo/.env | cut -d= -f2-)" -s -o /dev/null -w "proxy=%{http_code} t=%{time_total}\n" "https://uop.quark.cn/cas/ajax/getTokenForQrcodeLogin?client_id=532&v=1.2&request_id=t"
```

期望：`proxy=200` 且 `t` 在 **0.2–0.6s**（直连是 6s 级）。

然后在站上点解析，目录树应该 **1–3 秒**出来（此前 5–15 秒）。

## 四、可调参数

| 变量 | 默认 | 作用 |
|---|---|---|
| `HTTPS_PROXY` | 空 | 配了就优先走 curl + 代理 |
| `PAN_CURL_TIMEOUT` | 25 | 单请求超时（秒），配代理后可降到 12 |
| `PAN_RANGE_CONCURRENCY` | 6 | 多连接并发数，带宽够可调 8–10 |
| `PAN_DOWNLOAD_RATE` | 2 MB/s | 服务器中转限速，配代理后可提到 4–6 MB/s |

## 五、没有国内机器时的退路

| 方案 | 效果 | 成本 |
|---|---|---|
| 阿里云全球加速 GA | 大陆 → 香港走专线，RTT 降到 30–60ms | 按带宽计费，较贵 |
| 阿里云 DCDN | 静态资源加速好，动态接口仍需回源 | 需域名备案 |
| 不配，靠多连接并发 | 解析 5–15s、下载 ~700 KB/s | 0 |

第三条现在就是可用状态，配代理只是把「解析等待」从十几秒压到一两秒。
