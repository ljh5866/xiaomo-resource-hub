# 30 · 站内网盘解析（MVP：夸克）

> 需求（2026-11-06）：详情页每条网盘链接加一个跳转，点进站内解析页；**必须登录**；
> **只能解析当前这一条链接**（不开放任意 URL 输入）。目标平台：夸克 / 百度 / UC / 迅雷。

## 1. 形态

```
/r/{slug}  下载区每条夸克/百度/UC/迅雷卡片
   └─ 「站内解析 →」          ← 仅这四家出现，跳 /parse/{linkId}
        /parse/{linkId}
          ├─ 服务端：未登录 → /login?next=/parse/{linkId}
          ├─ 服务端：按 id 查库，取出 url/provider/提取码（前端无法替换成别家链接）
          ├─ 自动解析：列出分享根目录
          ├─ 点文件夹 → 逐层进入（面包屑返回）
          └─ 点「获取直链」→ 返回平台签发的下载地址
```

**为什么必须用 linkId 而不是让用户粘链接**：一旦开放输入框，这个页面就成了「免费解析站」，
别人的脚本会拿你的服务器和账号当代理。用 id 之后，能解析的只有你已经收录、并且愿意公开的那批。

## 2. 已实现（夸克）

链路照 YunX-Desktop 的 `QuarkConstants` 复刻，全部是明文 HTTP：

| 步骤 | 接口 | 是否需要登录 |
|---|---|---|
| 换 token | `POST drive-pc.quark.cn/1/clouddrive/share/sharepage/token`（pwd_id + passcode） | 否 |
| 列目录 | `GET .../share/sharepage/detail`（stoken + pdir_fid） | 否 |
| 转存 | `POST .../share/sharepage/save` | **是** |
| 取直链 | `POST .../file/download`（fids） | **是** |

实测（2026-11-06，匿名，不带任何 Cookie）：

```
root:  total=1
in "…第244讲": total=1
FILE …/WfSEv_…【PC】【Steam重置版】.mp4 | 11039 MB | token=yes
```

也就是说：**列目录、逐层浏览、拿到 share_fid_token 全部可行，不需要凭证**；
只有最后一步「转存 + 取直链」需要 `QUARK_COOKIE`。

## 3. 开通直链需要什么

服务器 `.env` 加一行（夸克网页版登录后的完整 Cookie）：

```bash
QUARK_COOKIE="__puus=...; __pus=...; ..."
```

没有它时，解析页会正常列出文件，但每条文件下方会提示「服务器未配置夸克登录凭证，只能看列表」，
点「获取直链」返回 `no-credential`。

## 4. 代码结构

| 文件 | 作用 |
|---|---|
| `src/lib/pan/types.ts` | provider 联合类型、分享 URL 解析、`PanFail` 错误码 |
| `src/lib/pan/quark.ts` | 夸克四条接口 + `hasCredential()` |
| `src/lib/pan/index.ts` | 分发 + **stoken 服务端内存缓存（10 分钟，不下发前端）** |
| `src/app/api/pan/resolve/route.ts` | 列目录（支持 pdirFid 进子目录） |
| `src/app/api/pan/direct/route.ts` | 取直链 |
| `src/app/(front)/parse/[id]/page.tsx` | 解析页（登录校验 + noindex） |
| `src/components/parse/parse-panel.tsx` | 客户端面板：自动解析、目录浏览、直链复制 |
| `src/components/resource/link-row.tsx` | 四家网盘卡片底部加「站内解析 →」 |

安全边界：

- API 只接受 `linkId`，服务端自己查 `resource_links`，前端构造不出别人的分享
- `stoken` 只存在服务端 Map，前端只拿 `fid` 和 `share_fid_token`
- 两个 API 都要求登录（未登录 401），解析页 `robots: noindex`
- 解析页只认 `status='published'` 的资源
