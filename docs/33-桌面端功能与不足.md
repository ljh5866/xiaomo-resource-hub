## 三、不足

### A. 功能缺失（用户会立刻发现）

| # | 缺什么 | 影响 | 补的成本 |
|---|---|---|---|
| A1 | **收藏 / 历史** | 桌面端最该有的功能没有，看完就丢 | 半天（本地 SQLite 或 localStorage） |
| A2 | **排序** | 只能按发布时间倒序，不能按名称/大小/更新时间 | 1 小时（后端加 `sort` 参数） |
| A3 | **页码跳转** | 只有「加载更多」，翻到第 30 页要连点 30 次 | 2 小时 |
| A4 | **设置页** | API 基址只能开控制台改 localStorage，普通用户做不到 | 2 小时 |
| A5 | **深色模式** | 系统深色时界面还是亮色 | 半天（CSS 变量已就位，加一套 media query） |
| A6 | **键盘快捷键** | 不能 `/` 聚焦搜索、`Esc` 返回 | 1 小时 |
| A7 | **托盘常驻 / 剪贴板识别** | 复制网盘链接不会提示，桌面端「助手」属性缺失 | 1 天 |
| A8 | **内置下载器** | 点链接只能唤起浏览器；无法多连接直下 | 2–3 天（可复用网站 `/api/pan/download`） |
| A9 | **离线缓存** | 断网 = 白屏（无 SW、无本地库） | 1 天（如果要做全离线） |

### B. 体验缺陷

| # | 问题 | 现状 |
|---|---|---|
| B1 | 搜索用的是 **SQL LIKE**，不是网站的 FTS5 中文分词 | 单词/短语够用，长句召回差于网页版 |
| B2 | 切换分类/标签时**整页重载**，无骨架屏 | 会闪一下「载入中…」 |
| B3 | 图片**无 LQIP/占位**，无封面时只显示「无封面」文字 | 弱网时一片灰 |
| B4 | 请求失败只有一行红字，**没有重试按钮** | 要手动切分类才重试 |
| B5 | 搜索结果**无关键词高亮** | — |
| B6 | 详情页正文按**纯文本**渲染（`white-space: pre-wrap`） | Markdown 的标题/列表/链接语法原样显示 |
| B7 | 窗口尺寸/位置**不记忆** | 每次都是 1180×780 居中 |
| B8 | 无 loading 骨架、无空状态插画 | 视觉上偏朴素 |

### C. 技术风险

| # | 风险 | 说明 |
|---|---|---|
| C1 | **强依赖站点可用性** | 站点 502 / 部署重启期间桌面端直接白屏 |
| C2 | **CSP 的 `connect-src` 写死** `localhost:3100` | 换本地端口联调要改 `tauri.conf.json` |
| C3 | **未做签名** | Windows SmartScreen 会弹「未知发布者」，需要用户点「仍要运行」 |
| C4 | **只出了 NSIS 安装包** | 没有 portable / MSI；绿色版用户没有选择 |
| C5 | **Win10 需 WebView2 运行时** | 缺失时安装包要引导安装（`nsis` 已配 `installMode: currentUser`，未验证引导流程 ⚠️） |
| C6 | **安装后首次运行未实测** ⚠️ | 构建成功、exe 能起，但 NSIS 安装包**没有实际装机验证过** |
| C7 | API 无鉴权、无限流 | 只读接口被刷的风险（数据本身是公开内容，影响有限） |

| # | 缺什么 |

## 七、一句话结论

**能用了，但只是「网站的壳」**：浏览、筛选、搜索、看详情、跳下载全部可用，体积小到 1.17 MB。
它现在还缺三样让它成为「桌面端」而不是「网页套壳」的东西：**本地收藏**、**托盘/剪贴板**、**内置下载**。
