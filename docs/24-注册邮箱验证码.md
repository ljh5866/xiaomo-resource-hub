# 24 · 注册接入邮箱验证码（QQ SMTP）

> 日期：2026-11-05 ｜ 状态：注册必须邮箱验证码，本地 e2e 通过；SMTP 待配

---

## 一、为什么加

原来注册只要邮箱 + 密码，存在两个问题：

1. **假邮箱能注册**：`a@a.com` 也能通过，将来找回密码时会发现邮箱是废的
2. **刷号零成本**：虽然有 IP/邮箱限速，但换个邮箱就能继续

加验证码后：邮箱必须是真实可收信的，且刷号要先付出发邮件的成本。

---

## 二、流程

```
填邮箱 → 点"获取验证码" → 服务端生成 6 位码并入库（只存哈希）
       → 发 QQ 邮件 → 用户填码 + 密码 → 校验通过才建号
```

前端有 60 秒倒计时，服务端也有冷却（重启不丢）。

---

## 三、配置 QQ 邮箱 SMTP

1. 登录 [mail.qq.com](https://mail.qq.com) → 设置 → 账号
2. 找到「POP3/IMAP/SMTP/Exchange/CardDAV/CalDAV 服务」
3. 开启 **POP3/SMTP 服务**（要短信验证）
4. 点「生成授权码」，得到 16 位字符串 —— **这就是 SMTP_PASS，不是 QQ 密码**

然后写进 `.env`：

```ini
SMTP_HOST=smtp.qq.com
SMTP_PORT=465
SMTP_USER=123456789@qq.com
SMTP_PASS=abcdefghijklmnop
SMTP_FROM="小莫资源网 <123456789@qq.com>"
```

> 465 走 SSL，587 走 STARTTLS。代码里按端口自动选。

改完 `sudo systemctl restart xiaomo` 生效，不用重新构建。

---

## 四、防滥用

| 限制 | 规则 |
|---|---|
| 单邮箱频率 | 60 秒冷却 + 每小时 5 次 |
| 单 IP 频率 | 每小时 10 次 |
| 验证码有效期 | 10 分钟 |
| 错误次数 | 累计 5 次作废，需重新获取 |
| 一次性 | 校验成功立即标记 `consumed_at` |
| 存储 | 库里只存 `sha256(code + AUTH_SECRET)`，泄露也拿不到码 |

验证码用 `crypto.randomInt` 生成，不用 `Math.random`。

---

## 五、本地怎么测（不发真邮件）

```bash
EMAIL_DEV_MODE=1 pnpm dev
```

点了「获取验证码」后：

- 服务端日志会打印 `[email-code] xxx@x.com → 123456`
- 同时写入 `data/.dev-emails.log`（一行一条，制表符分隔）

`scripts/test-register.mjs` 就是从这个文件读码的，所以 e2e 不需要真邮箱。

`pnpm verify` 起临时服务时自动带 `EMAIL_DEV_MODE=1`。

## 六、数据表

`006_email_codes.sql`：

```sql
email_codes(id, email, code_hash, purpose, expires_at, attempts, consumed_at, created_at, ip_hash)
```

`purpose` 现在只有 `register`，将来找回密码用 `reset` 复用同一张表。

清理：`pruneCodes()` 删掉 24 小时前的记录，可以由维护定时任务调用。
