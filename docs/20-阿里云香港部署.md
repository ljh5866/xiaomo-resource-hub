# 20 · 阿里云香港：从下单到上线

> 适用：阿里云**轻量应用服务器（SWAS）**香港地域，Ubuntu 24.04
> 特点：境外地域**不需要 ICP 备案**；国内访问 30–80ms；出网按流量包计费

---

## 一、买之前要确认的三件事

| 项 | 结论 |
|---|---|
| 需不需要备案 | **不需要**。香港属境外地域，域名解析过去可以直接访问 |
| 域名在哪 | 阿里云域名 + 阿里云香港服务器是最省事的组合（解析在同一控制台） |
| 预算 | 香港比国内贵：2核2G 大约 ¥60–120/月，促销年付会便宜些；**以官网为准** |

⚠️ 香港轻量的带宽是「**峰值带宽 + 月流量包**」（例如 30Mbps / 1000GB）。超流量会限速或按量计费，
我们这个站是文字 + 小图，正常访问远用不完；但**别把备份往这台机器上堆太多**（备份已经在本地留存）。

## 二、下单

1. 阿里云控制台 → **轻量应用服务器** → 创建
2. **地域：中国香港**
3. **镜像：系统镜像 → Ubuntu 24.04**（不要选带宝塔/WordPress 的应用镜像）
4. **规格**：2核 2G（1核1G 会在 `pnpm build` 时 OOM）
5. **磁盘**：40G 起（依赖 ~600M + 构建缓存 + 备份）
6. **时长**：先买 1 个月试，跑通再续年付（年付通常有折扣）
7. **登录凭证**：自定义 root 密码（买完立刻换成密钥登录）

买完在控制台记下三样东西：**公网 IP**、**root 密码**、**防火墙（安全组）入口**。

### 国际型套餐怎么读

阿里云香港「国际型」有三档常见配置，我们的选择是中间那档：

```
¥28/月   2 vCPU · 1 GiB  · 30 GiB 盘 · ¥28
¥39/月   2 vCPU · 2 GiB  · 40 GiB 盘 · 200 Mbps · 无固定流量   ← 选这个
更上一档 4 vCPU · 4 GiB  · 起步价翻倍，当前项目用不上
```

四个词值得解释：

| 字段 | 含义 | 对我们的影响 |
|---|---|---|
| **BGP（非中国优化）** | 国际线路，回国内可能绕路 | 延迟 60–150ms，晚高峰可能抖动；要国内快就得选「中国优化」套餐或后加 CDN |
| **无固定流量** | 不按流量计费，只受峰值带宽限制 | 对我们很友好：不怕备份/图片把流量跑超 |
| **200 Mbps 峰值** | 共享带宽，突发能到，跑满不保证 | 静态站完全够 |
| **2 GiB 内存** | ✅ 刚好够 `pnpm build`（峰值 1.2–1.8G） | 构建 40–60 秒；不要选 1 GiB 那档 |

> 1 GiB 那档（¥28）也不是不能跑，但要靠 swap + 限堆，构建慢到 2–4 分钟。
> 十几块钱差价换每次发版不折腾，值得。

## 二·五、1G 内存怎么办

`pnpm build` 的峰值内存是 **1.2–1.8G**，1G 机器直接跑会被 OOM killer 杀掉（表现是
`Killed` 或构建到一半没输出）。三条路，按推荐顺序：

**① 有 2G 套餐就买 2G**（最省事，多花十几块）

**② 没有 2G 就用 swap + 限堆**（能跑，构建 2–4 分钟）：

```bash
bash deploy/bootstrap-ubuntu.sh     # 里面已经建了 2G swap
bash deploy/build-lowmem.sh         # 限堆 1024MB 再构建，并打印内存
```

`build-lowmem.sh` 干两件事：确保 swap 存在、用
`NODE_OPTIONS=--max-old-space-size=1024` 限制 V8 堆，避免进程被直接杀掉。

**③ 本地构建后上传**（不推荐）：静态资源能用，但 `sharp` 是平台相关的原生模块，
Linux 上还得重装依赖，容易变成「本地好好的、服务器跑不起来」。

> 判断标准：如果构建时 `free -m` 的 available 长期贴着 0、swap 用得飞起，
> 说明这台机器太小了，后面的每次发版都要难受一次——不如换规格。

## 三、控制台放行端口

轻量服务器有两层防火墙，容易踩坑：

1. **轻量控制台 → 防火墙**：添加规则 `TCP 80`、`TCP 443`、`TCP 22`
2. 服务器内部还有 `ufw`（初始化脚本会开）

只开 22 不放 80/443，表现就是"域名打不开、但 SSH 正常"——90% 的第一次部署卡在这。

## 四、服务器初始化（一条命令）

```bash
# 用 root 登进去，把脚本传上去（或直接在服务器上 git clone 仓库）
scp deploy/bootstrap-ubuntu.sh root@<公网IP>:/root/
ssh root@<公网IP>
bash /root/bootstrap-ubuntu.sh          # 装环境：时区/swap/字体/Node24/pnpm/Caddy/目录
```

脚本做六件事，都不碰你的代码：

| 步骤 | 内容 |
|---|---|
| 时区 | `Asia/Shanghai`（日志时间才对得上） |
| swap | 2G（内存兜底，构建时救命） |
| 字体 | `fonts-noto-cjk`（**分享图的中文靠它**） |
| Node | 24.x + pnpm 10（corepack） |
| Caddy | 官方源安装，自动 HTTPS |
| 目录 | `/var/www/xiaomo/data/{uploads,backups}` |

想顺便加固（建 deploy 用户、禁密码登录、开 ufw）：

```bash
# 前提：你已经把公钥放进 /root/.ssh/authorized_keys，否则会被锁在外面
bash /root/bootstrap-ubuntu.sh --harden
```

## 五、部署这个项目

```bash
cd /var/www/xiaomo
git clone <你的仓库> .        # 或者 rsync 上传

cp .env.example .env
nano .env
```

`.env` 香港部署长这样：

```ini
SITE_URL=https://你的域名
DATABASE_URL=/var/www/xiaomo/data/app.db
AUTH_SECRET=<openssl rand -hex 32 的输出>
```

```bash
pnpm install --frozen-lockfile
pnpm db:migrate
pnpm user:add 你的邮箱 '强密码' --admin
pnpm build

cp deploy/xiaomo.service /etc/systemd/system/
cp deploy/xiaomo-maintenance.{service,timer} /etc/systemd/system/
systemctl daemon-reload
systemctl enable --now xiaomo
systemctl enable --now xiaomo-maintenance.timer

chown -R www-data:www-data /var/www/xiaomo/data
```

## 六、域名与 HTTPS

1. 阿里云 DNS → 添加 `A` 记录：`@` 和 `www` 都指向香港公网 IP，TTL 600
2. 改 Caddy 配置：

```bash
nano /etc/caddy/Caddyfile     # 把 example.com 换成你的域名
systemctl reload caddy
journalctl -u caddy -f        # 看证书申请过程（Let's Encrypt，约 30 秒）
```

3. 验证：

```bash
curl -fsS https://你的域名/api/health
# {"ok":true,"app":"xiaomo","db":{"latencyMs":3,...}}
```

> 香港机器 + 境外域名解析**不需要备案**；但如果之后想用国内 CDN 加速，CDN 域名要备案。
> 一开始直连就够了。

- [ ] `systemctl status xiaomo` 是 `active (running)`
- [ ] `curl https://域名/api/health` 返回 `ok:true`

## 八、香港机型的三个注意点

| 注意 | 说明 |
|---|---|
| 流量包 | 30Mbps 峰值 + 月流量，超了限速。图片多的话留意后台流量图 |
| IP 被墙 | 境外 IP 偶发 443 不通。真遇到在控制台换弹性公网 IP |
| 备份别只放机器上 | 定时任务已经每天打包到 `data/backups`，建议每周用 `scp` 拉回本地一份 |

## 九、以后要迁移

换机器（换地域、换云厂商）只有四步，因为所有状态都在 `data/` 和 `.env` 里：

```bash
# 旧机
pnpm backup && scp -r data/backups/<最新> 新机:/tmp/xiaomo-backup

# 新机
git clone … && pnpm install && pnpm db:migrate
cp /tmp/xiaomo-backup/app.db data/app.db
cp -r /tmp/xiaomo-backup/uploads/* data/uploads/
pnpm build && systemctl restart xiaomo
```

DNS 一改，几分钟就切过去了。
