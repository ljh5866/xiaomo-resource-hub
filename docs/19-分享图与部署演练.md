## 一、分享图

### 为什么不用 next/og

Next 自带的 `ImageResponse`（Satori）**必须打包字体文件**才能渲染中文，否则全是方块。
一个中文字体子集动辄几百 KB，还要处理字重、fallback。

我们已经有 `sharp`（封面链路在用），而 sharp 直接吃系统字体——一条 SVG 字符串就够了：

```ts
const png = await sharp(Buffer.from(svg), { density: 144 }).resize(1200, 630).png().toBuffer();
```

代价是**服务器必须装中文字体**（Debian: `apt install fonts-noto-cjk`）。
这条已经写进部署清单，演练脚本也会检测。

### 接口

```
GET /api/og?title=模板文档&sub=Excel / PPT / Word 模板&tag=分类 · 共 12 项
    → image/png 1200×630
    Cache-Control: public, max-age=86400, stale-while-revalidate=604800
```

参数只有三个：`title`（大字）、`sub`（第二行）、`tag`（左上角小字）。
缺省时用站点名，所以任何页面都能兜底。

### 视觉

沿用「卡片目录柜」：墨绿黑底 + 细网格纹理（就是卡片目录的抽屉格）+ 黄铜底边 +
左上角「莫」字方框 + 右下角品牌行。标题超过 12 个字会降到 68px，超过 17 个字截断加省略号
（`fitText()`，中文按 1em、英文按 0.55em 估算宽度）。

### 各页面怎么用

| 页面 | 分享图 |
|---|---|
| 首页 | 站点名 + 「认真归档的好用资源 · 只做索引」 |
| 分类页 | 分类名 + 描述 + 「分类 · 共 N 项」 |
| 标签页 | `#标签名` + 「标签聚合」 |
| 详情页 | **有封面直接用封面**；没封面用标题卡（标题 + 摘要 + 分类·编号） |

详情页优先用封面是有意的：真实截图比程序生成的标题卡更有点击率。

同时补了 `twitter:card = summary_large_image`——Telegram、Slack、X 都认这个。

## 二、部署演练

Windows 上跑不了 systemd / Caddy，但**能演练的部分比想象中多**：

```
node scripts/drill-deploy.mjs
```

| 检查 | 做法 |
|---|---|
| 部署物料 | 读 5 个文件，验证关键指令存在（`ExecStart` / `OnCalendar` / `reverse_proxy` / `health_uri` / `git pull`…） |
| 环境变量 | `AUTH_SECRET` ≥32 位且不是示例值、`SITE_URL` 已配置且不是 localhost |
| **备份恢复** | 跑一次 `backup.mjs` → 把快照复制到临时目录 → 打开它核对 5 张表的计数 → 再查一次 published 确认能查询 |
| 中文字体 | 用 sharp 渲染一段中文（Linux 上额外 `fc-list :lang=zh` 计数） |

输出长这样：

```
✓ 部署物料：5 个文件，关键指令齐全
! 环境变量：SITE_URL 还是本地地址（上线前改成域名）
✓ 备份恢复：快照 2026-11-03T15-49-02：resources=0 links=0 categories=7，查询可用（published=0）
✓ 中文字体：渲染成功 200×80
```

最后打印**必须在服务器上做**的 6 件事（装服务、改 Caddyfile、开定时器、健康检查、
装中文字体、验证 data 目录权限）——这些本地确实无法演练，写清楚比假装演练过更诚实。

### 第一次跑就抓到一个真错

备份恢复检查报 `ENOENT: copyfile …`：我把快照复制到临时目录时**没先建目录**。
`fs.copyFileSync` 不会帮你创建父目录。修完才通过。

> 这类错误正是演练的意义：真出事时才发现"恢复脚本第一步就挂"，损失的是线上停机时间。

## 三、验收

```bash
node scripts/test-og.mjs        # 1200×630 PNG + 三个页面都有 og:image / twitter:card
node scripts/drill-deploy.mjs   # 物料 / 环境 / 备份恢复 / 字体
```

`test-og.mjs` 会真的把图下载下来，用 sharp 读 `metadata()` 断言尺寸是 1200×630、
字节数 > 5KB（挡住"返回了空图"这种假成功）。
