## 一、产品定位

**小莫资源网**是一个面向中文用户的**资源索引与分发站**：不生产资源，只做**整理、结构化、去失效、可检索**。

### 定位陈述

> 对「找软件、找素材、找模板、找教程」的人，小莫是**比网盘搜索更干净、比论坛更结构化**的那一层索引。
> 它不托管大文件，但它保证：**你点开的每一条链接，昨天还有人验证过它还活着。**

### 与三类竞品的差异

| 对手类型 | 代表 | 他们的强项 | 小莫的差异点 |
|---|---|---|---|
| 网盘聚合搜索 | panhub / pansou | 覆盖广、结果多 | 小莫**少而准**：人工过审 + 结构字段 + 失效标记 |
| 导航站 | WebStack / 前端导航 | 布局成熟 | 小莫是**资源站不是链接簿**：有版本、大小、平台、更新说明 |
| CMS 资源站 | 苹果CMS / RiPro 系 | 采集快、量大 | 小莫**不做采集堆量**，做人工策展与长期可维护性 |

## 二、目标用户与场景

### 主用户画像

| 画像 | 占比预估 | 典型诉求 | 关键路径 |
|---|---|---|---|
| **效率型打工人**（25–35，非技术） | 45% | "给我一个能用的 Excel 模板 / PPT 模板 / 剪辑素材" | 首页分类 → 详情 → 复制链接 → 网盘 |
| **学生 / 自学者** | 30% | "找课程、找电子书、找破解工具的替代品" | 搜索框 → 结果 → 详情 → 下载 |
| **技术型用户**（开发者/设计） | 20% | "找工具、找字体、找图标库，要求版本准确" | 搜索 → 标签筛选 → 详情（看版本/校验） |
| **回头客 / 站长同行** | 5% | 看更新日志、找灵感 | RSS / 每日更新页 |

### 三个必须打通的场景

1. **"我知道要什么"** → 搜索框输入 → 3 秒内出结果 → 详情页一键复制链接（含提取码）。
2. **"我不知道有什么"** → 首页分类网格 → 逛 → 收藏。
3. **"上次那个东西呢"** → 收藏夹 / 浏览历史 / 资源编号直达。

## 三、范围边界（Scope）

### ✅ MVP（v1.0，必须有）

| 模块 | 具体内容 | 验收标准 |
|---|---|---|
| 首页 | 分类入口 + 精选资源 + 最新更新 + 搜索框 | LCP < 2.0s，首屏无布局跳动 |
| 分类页 | 按资源类型聚合，分面筛选（平台/网盘/时间） | 500 条数据下翻页流畅 |
| 详情页 | 结构化字段 + 说明 + 多链接列表 + 提取码复制 | 复制成功率 100%，含降级方案 |
| 搜索 | 标题/标签/简介全文检索，中文分词 | Top3 命中率 > 80%（20 条测试集） |
| 标签 | 标签聚合页 | — |
| 后台 | 资源 CRUD、分类管理、批量导入（CSV/JSON） | 10 分钟能录 50 条 |
| 链接巡检 | 定时任务检查链接存活，标记失效 | 每日跑一次，失效 24h 内降权 |
| 收藏 | 登录用户收藏 | — |
| SEO | sitemap、结构化数据、OG 卡、RSS | 提交 Search Console 无错误 |

### ⏳ V1.1（上线后 4 周内）

- 用户投稿（提交资源 → 审核 → 上架）
- 失效举报（用户点"链接挂了"→ 进入巡检队列）
- 每日更新页 / 周报
- 微信 / QQ 登录
- 下载统计与热门榜

### 🔮 V2（3 个月后，看数据再定）

- 会员 / 积分体系（解锁高速直链）
- 自建对象存储直链（小文件）
- 资源合集（"设计师开工包"这类打包策展）
- API 开放（给第三方调用）
- 移动端 PWA

### 🚫 明确不做（写下来防止自己跑偏）

| 不做 | 原因 |
|---|---|
| 托管大文件 / 做网盘 | 带宽与存储成本不可控，且与"索引"定位冲突 |
| 自动采集全网资源 | 质量崩塌 + 重复 + 失效率爆炸（见 00 文档反面教材） |
| 论坛 / 评论区（MVP 阶段） | 审核成本高，先靠"举报"这一个轻交互 |
| 付费墙（MVP 阶段） | 没流量先做付费是自杀；先把免费流量做起来 |
| 多语言 | 中文单语，把一件事做透 |
| 原生 App | 响应式 Web 足够，PWA 在 V2 再看 |

## 四、指标体系（怎么算做成了）

### 北极星指标

> **周有效下载次数**（用户点击链接且 7 日内该链接仍有效）

选它的理由：既衡量流量，也衡量"资源还活着"这个核心承诺。

### 分层指标

| 层级 | 指标 | MVP 目标（上线 30 天） | 90 天目标 |
|---|---|---|---|
| 获取 | 自然搜索 UV / 周 | 300 | 3,000 |
| 获取 | 收录页面数 | 200 | 2,000 |
| 激活 | 详情页 → 点击下载 转化率 | ≥ 35% | ≥ 45% |
| 留存 | 7 日回访率 | ≥ 12% | ≥ 20% |
| 质量 | 死链率（抽查 100 条） | ≤ 8% | ≤ 3% |
| 质量 | 搜索无结果率 | ≤ 25% | ≤ 12% |
| 内容 | 周新增过审资源 | 40 | 80 |

> 早期**不要看 PV**，看"死链率"和"搜索无结果率"——这两个数字直接决定用户会不会再来。

### M1 · 工程骨架与内容模型（11-10 → 11-16，1 周）

- Next.js 16 + TS + Tailwind v4 脚手架，接入 DESIGN.md 的 tokens
- Drizzle schema 落库 + 种子数据（30 条真实资源）
- 布局骨架：Header（搜索条）、Footer、分类 Rail
- 基础组件：Button / Card / Badge / Input / Dialog / Toast（shadcn 风格手写）
- 路由骨架：`/` `/c/[slug]` `/r/[slug]` `/search`

**验收**：本地 `pnpm dev` 能跑通 4 个页面，Lighthouse 性能 ≥ 90（空数据）

---

### M2 · 前台核心（11-17 → 11-30，2 周）

- 首页：分类网格 + 精选 + 最新
- 分类页：分面筛选 + 无限滚动/分页
- 详情页：结构化字段 + 链接列表 + 提取码复制 + 失效提示
- 搜索：FTS5 + jieba 切词 + 结果高亮 + 空状态引导
- 标签页、收藏、404/500、loading 骨架屏
- 全站响应式（375 / 768 / 1024 / 1440）+ 键盘可达 + 暗色模式

**验收**：30 条种子数据下，全部页面可用；移动端 375px 无横向滚动；所有交互有 focus 态

---

### M3 · 后台与运维（12-01 → 12-11，1.5 周）

- `/admin` 登录（Auth.js + 邮箱验证码，单管理员起步）
- 资源 CRUD（含 Markdown 说明、多链接编辑、封面上传）
- 批量导入（CSV/JSON → 预览 → 去重 → 入库）
- 链接巡检 cron（HEAD/GET 探测 + 状态机 + 失效通知）
- 数据看板：新增数、死链数、Top 搜索词

**验收**：从 0 到 100 条资源录入 ≤ 40 分钟；巡检报告可读

---

### M4 · 上线与冷启动（12-12 → 12-21，1.5 周）

- 生产部署（VPS + Caddy + PM2/systemd）+ HTTPS
- 备份策略（每日 DB 快照 → 对象存储）
- SEO：sitemap / robots / 结构化数据 / OG 图自动生成
- 监控：uptime + 错误日志 + 简单埋点
- 内容冷启动：200 条过审资源铺底
- 提交搜索引擎、发 3 个渠道做首批曝光

**验收**：域名可访问、HTTPS A 级、Search Console 收录 > 0
