## 一、封面链路（M2-b）

```
选图 → POST /api/upload → sharp 处理 → data/uploads/covers/{hash}.webp
                                        ↓
                              DB: cover_url / cover_blur
                                        ↓
                        资源卡 / 详情页 <img> + LQIP 底色
```

| 环节 | 实现 |
|---|---|
| 上传 | `POST /api/upload`，字段 `file`，上限 8MB，只收 jpg/png/webp/avif/gif |
| 处理 | `sharp` 自动旋转 → 限宽 webp q=82；同时生成 32×20 的 base64 模糊图 |
| 存储 | 本地磁盘驱动 `data/uploads`，文件名是内容哈希（同图不重复写） |
| 分发 | `/files/[...path]` 路由，`Cache-Control: immutable`（文件名即版本） |
| 展示 | 卡片 `<img loading="lazy">` + `background-image: blur` 防抖；无图回落「目录卡」纹理 |
| 更换存储 | 只改 `src/lib/storage.ts` 的 `processCover / readFile`，R2/OSS 各写一个实现即可 |

**为什么不用 next/image**：图片在服务端已经压成唯一尺寸的 WebP，再走一次优化管线等于二次编码；
而且上传文件在运行时写入，`next/image` 需要一个可枚举的域名白名单。这里用原生 `<img>` + 显式尺寸 + LQIP，CLS 一样是 0。

### 种子封面

`pnpm covers:gen` 会按分类色调 + 资源编号生成 24 张品牌封面（SVG → WebP，约 10KB/张）。
好处：演示环境不依赖外部图床，视觉风格与「卡片目录柜」一致，也让上传链路的产物有真实样本。

> 换真图时：后台资源编辑页「封面」→ 选图 → 保存即可，生成图会被覆盖为 `cover_url`。

## 二、收藏（M2-c 过渡版）

还没接账号，先用 **httpOnly cookie 存资源 id 列表**，让收藏功能可以先跑起来。

| 件 | 位置 |
|---|---|
| 读写 cookie | `src/lib/favorites.ts`（`readFavIds` / `serializeFavIds`） |
| 切换接口 | `POST /api/favorite` → `{ ok, favorited, count }` |
| 按钮 | `src/components/resource/favorite-button.tsx`（乐观更新，失败回滚） |
| 列表页 | `/favorites`（读 cookie → 查库 → 复用资源卡） |

上限 200 条，`SameSite=Lax`、`httpOnly`，有效期 1 年。

**接 Auth.js 时的迁移点**：只换 `readFavIds` 的实现（改成查 `favorites` 表），
按钮与页面零改动；必要时做一次 cookie → 表的迁移。

## 三、单元测试

不引 vitest/jest，用 Node 内置 test runner + tsx：

```bash
pnpm test
```

```
✔ 识别「提取码：xxxx」
✔ 中文按 2-gram 切分
✔ formatCount 分级
… 共 15 条，全部通过
```

覆盖了三个最容易悄悄出错的纯函数：**中文切词、提取码嗅探、数字/日期格式化**。
（这三处一旦错，搜索、录入、列表展示都会错，而且不会报错，只会"看起来不对"。）

## 四、这一轮踩的坑

| 坑 | 现象 | 解法 |
|---|---|---|
| `ChipRow` 双重包裹 | 卡片上的标签出现双层边框、比预期粗 | `ChipRow` 内部已经包了 `<Chip>`，调用方传字符串而不是 `<Chip>` 元素 |
| tsconfig 拒绝 `.ts` 后缀导入 | `pnpm build` 报 TS5097，但 `pnpm test` 正常 | 开 `allowImportingTsExtensions: true`（Node 跑测试需要带后缀，构建需要允许） |
| 详情页封面过高 | 800×500 的图在正文里占近 480px | `max-h-[420px]` + `object-cover`，保留比例不塌 |
