# 17 · 内容流水线：链接清单 → CSV → 导入

> 日期：2026-11-03 ｜ 状态：一次能进几十条，人工只负责审标题与分类

---

## 一、为什么做这个

"内容铺底"是这个项目唯一靠写代码解决不了的事，但**录入效率**可以。

手工在后台一条条填：标题、slug、分类、网盘、链接、提取码、大小、版本、摘要——9 个字段，
一条 1~2 分钟，100 条就是两三个小时，而且很容易把提取码抄错。

所以做了三段流水线，人只做"审"这一步：

```
links.txt（一堆分享链接）
   ↓ pnpm import:links links.txt --cat template
data/import/batch.csv（自动识别网盘、抓标题、猜提取码）
   ↓ 打开检查 / 改标题
后台 → 批量导入（粘贴 CSV）
   ↓
资源入库（自动编号 + 索引重建）
```

---

## 二、两个入口

### 1. 可视化：下载模板 → 填 → 粘贴

后台 `/admin/imports` 页现在有：

- **下载 CSV 模板**按钮（`/import-template.csv`，带 BOM，Excel 打开不乱码）
- 列说明表格（哪些必填、每个字段什么格式）
- 粘贴框 + 「填入示例」按钮 + 行数统计

### 2. 命令行：从链接清单生成

```bash
# links.txt 每行一个链接，可在链接前写标题
pnpm import:links links.txt --cat template --out data/import/batch.csv
```

它会：

| 能力 | 说明 |
|---|---|
| 识别网盘 | 按域名映射到 quark / baidu / aliyun / xunlei / 123，认不出记 other |
| 保留行内标题 | `Excel 模板合集 https://…` 这种写法会取前半段做标题 |
| 抓落地页标题 | 行内没标题时去抓 `og:title` / `<title>`，6 秒超时 |
| 猜提取码 | 从 `?pwd=xxxx` 或「提取码: xxxx」里提 |
| 兜底标题 | 抓不到就写「待补标题 3」，导出后手改 |
| slug 生成 | 英文转 kebab-case；中文用稳定短哈希（同样输入同样输出） |

## 三、实现要点

**CSV 工具是纯函数**（`src/lib/csv.ts`），所以能单测：

```ts
csvEscape('说 "你好"')      // → '"说 ""你好"""'
parseCsvLine('a,"b,c",d')   // → ["a", "b,c", "d"]
```

往返一致性也测了：`parseCsvLine(rowToCsv(row))` 必须等于原数组——
这一条能挡住"自己生成的 CSV 自己导不回去"这种尴尬。

**转义规则**：含逗号 / 双引号 / 换行的字段用双引号包起来，内部引号写两遍，
换行压成空格（否则一行会变成两行，导入器按行解析就崩了）。

**表头识别放宽**：导入器原来只认 `title` 开头，现在 `标题` 开头也跳过——
因为模板是中文表头，不认的话第一行会被当成数据报错。

```

front    → 后台能搜到刚导入的资源

```
