# 03 · 信息架构与页面清单

> 这份文档是**前端任务单**：每一页有什么、按什么顺序、空状态长什么样。

## 一、路由总表

| 路由 | 页面 | 渲染 | 优先级 | 说明 |
|---|---|---|---|---|
| `/` | 首页 | ISR 10min | P0 | 分类入口 + 精选 + 最新 |
| `/c/[category]` | 分类页 | ISR 10min | P0 | 分类下资源列表 + 分面筛选 |
| `/r/[slug]` | 资源详情 | ISR 1h + 按需刷新 | P0 | 核心转化页 |
| `/search` | 搜索结果 | 动态 SSR | P0 | `?q=&cat=&provider=&sort=` |
| `/t/[tag]` | 标签页 | ISR 1h | P1 | 长尾流量入口 |
| `/updates` | 每日更新 | ISR 1min | P1 | 更新流，RSS 同步 |
| `/favorites` | 我的收藏 | 动态 | P1 | 需登录 |
| `/login` | 登录 | 动态 | P1 | 邮箱验证码 |
| `/go/[linkId]` | 下载跳板 | 动态 | P0 | 302，不渲染 UI |
| `/about` | 关于 / 来源说明 | 静态 | P2 | 信任背书 |
| `/admin/*` | 后台 | 动态 | P0 | 见第五节 |
| `/sitemap.xml` `/robots.txt` `/rss.xml` | 机器可读 | 静态 | P0 | SEO |
| `/404` `/500` | 错误页 | 静态 | P1 | 带搜索框，不是死胡同 |

> 命名强约束：**`/r/` 而不是 `/resource/`**，URL 越短越好；slug 用英文+连字符，不用中文拼音（可读且稳定）。

```
┌───────────────────────────────────────────────────────────────┐
│ [小莫资源网]   [🔍 搜索 12,400 个资源…        ]  [分类▾] [收藏] [登录] │  ← 64px
├───────────────────────────────────────────────────────────────┤
│                                                               │
│   页面内容区（最大宽度 1280，左右 24px 安全边）                  │
│                                                               │
├───────────────────────────────────────────────────────────────┤
│  关于 · 来源说明 · RSS · 举报失效 · © 2026 小莫资源网            │
└───────────────────────────────────────────────────────────────┘
```

**导航原则**

- 一级导航只有三个入口：**搜索框（视觉最重）→ 分类 → 收藏**。
- 分类不做顶栏横向滚动（超过 8 个就放不下），改为**首页网格 + 分类页左侧 rail**。
- 移动端：底部固定 3 个 tab（首页 / 分类 / 我的），搜索框吸顶。

## 三、页面详规

### 3.1 首页 `/`

**目标**：让第一次来的人 5 秒内知道"这里有我要的东西"，并开始点。

```
┌─────────────────────────────────────────────────────┐
│  HERO（不高，280px）                                  │
│  「找资源，别再翻十个网盘。」                            │
│  [ 大搜索框                          ] [搜索]         │
│  热门：Excel模板 · 剪辑素材 · 字体 · 效率工具           │
├─────────────────────────────────────────────────────┤
│  分类网格  8 张卡（图标 + 名称 + 资源数）                │
│  ┌────┐┌────┐┌────┐┌────┐                            │
│  │软件││模板││素材││教程│                             │
│  └────┘└────┘└────┘└────┘                            │
├─────────────────────────────────────────────────────┤
│  本周精选（编辑策展，3–6 条大卡）                        │
├─────────────────────────────────────────────────────┤
│  最新收录（12 条标准资源卡，每行 3/2/1 列）              │
│                                     [ 查看全部 →]     │
├─────────────────────────────────────────────────────┤
│  信任条：12,400 个资源 · 死链率 2.1% · 每日更新          │
└─────────────────────────────────────────────────────┘
```

**关键细节**

- 搜索框是页面上**唯一**的焦点元素（配色上用 accent 描边），其余元素降饱和。
- "信任条"是差异化武器：把死链率这个"负面指标"公开，反而建立信任。
- 空数据/冷启动时：分类网格照常展示，精选区显示"内容筹备中，先看看分类"。

**筛选器设计（重要）**

- 所有筛选状态**写进 URL**：`?platform=windows&provider=quark&sort=latest`
- 理由：可分享、可被收录、前进后退不出错。**不要用组件内部 state。**
- 筛选变化 → 局部刷新列表，不跳页；顶部保留已选筛选 chip，可单个 ×。

**资源卡（全站统一组件）**

```
┌──────────────────────────────────────┐
│ [封面 16:10，无圆角，LQIP 占位]         │
├──────────────────────────────────────┤
│ XM-2026-0417            ● 有效        │  ← 编号 + 状态点
│ Excel 数据看板模板合集                  │  ← 标题，2 行截断
│ 12 套可直接套用的经营分析看板            │  ← 副标题，1 行截断
│ [模板] [windows] [1.2GB] [夸克]        │  ← 元信息 chips
└──────────────────────────────────────┘
```

**状态点规则**：`●有效` 绿 / `●待校验` 灰 / `●失效` 红（但不隐藏）。

**下载区的体验细节（成败在此）**

| 场景 | 行为 |
|---|---|
| 点"夸克网盘" | 新窗口打开 `/go/{id}` → 302 到真实链接 |
| 提取码 | 自动复制到剪贴板 + Toast「提取码 abc1 已复制」；失败时降级为可选中文本 |
| 链接失效 | 按钮禁用 + 灰标「小编正在修复」+ 展示 `[举报失效]` + 展示备用链接 |
| 无备用链接且全失效 | 显示「这个资源挂了，通知我修好」→ 留邮箱进队列 |
| 未登录点收藏 | 弹出轻量登录，不跳页 |

**SEO 结构化**

- `SoftwareApplication`（软件类）/ `Article`（教程类）JSON-LD
- 面包屑 `BreadcrumbList`
- OG 图用 `opengraph-image.tsx` 动态生成（编号 + 标题 + 分类色块）

### 3.5 后台 `/admin`

| 页面 | 核心 | 验收 |
|---|---|---|
| `/admin` | 看板：今日新增、待校验链接、Top 搜索词、死链率 | 一眼看到"今天要干什么" |
| `/admin/resources` | 表格：编号/标题/分类/状态/链接状态/更新时间 + 搜索 | 1000 条下筛选不卡 |
| `/admin/resources/new` `/edit` | 表单：结构化字段 + Markdown + 多链接编辑器 | 键盘可完成 80% 操作，支持 `Ctrl+S` |
| `/admin/imports` | 三步向导：上传 → 预览去重 → 入库 | 50 条 CSV ≤ 3 分钟 |
| `/admin/links` | 巡检报告：新增失效列表、一键复测、批量改状态 | — |
| `/admin/categories` `/tags` | 排序、显隐、合并 | — |

**新建资源表单的关键设计**

- 链接编辑器是**数组卡片**：加一条 → 选 provider（下拉带官方色）→ 粘 URL → 自动嗅探提取码（正则 `提取码[:：]\s*([a-zA-Z0-9]{4})`）
- 保存时自动校验：`url_hash` 是否全站重复 → 重复则提示"这条链接已挂在 XM-2025-0231 下"
- 保存后自动：切词入 FTS、`revalidatePath` 相关页面、加入巡检队列

## 四、内容模型（运营视角）

### 一个资源上架的 6 个必填项

1. **标题** —— 用户会搜的那个词开头（"Excel 数据看板模板"，不是"分享一个好东西"）
2. **副标题** —— 一句话说清"有什么、给谁用"
3. **分类 + 类型** —— 决定它出现在哪个入口
4. **至少一条有效链接** —— 没有链接不算资源
5. **说明正文 ≥150 字** —— 写清楚：包含什么、怎么用、有什么坑。这是 SEO 与信任的全部来源
6. **来源台账** —— 来源页 URL + 授权/公开形式 + 记录日期

### 运营位（首页可编排）

| 位置 | 类型 | 更新频率 | 谁维护 |
|---|---|---|---|
| 本周精选 | 人工策展 3–6 条 | 每周一 | 人工 |
| 最新收录 | 自动按 `published_at` | 实时 | 自动 |
| 分类入口 | 静态配置 + 自动计数 | — | 配置 |
| 热门标签 | 按 `use_count` 自动 | 每日 | 自动 |
| 信任条 | 自动统计（资源数/死链率/更新数） | 每日 | 自动 |

## 五、SEO 策略

| 手段 | 具体做法 | 预期 |
|---|---|---|
| 详情页唯一性 | 每页 ≥150 字原创说明，禁止纯复制来源文案 | 避免被判低质 |
| 内链矩阵 | 详情页 → 同分类 3 条 + 同标签 3 条 + 上/下架推荐 | 提升收录深度 |
| 聚合页 | 分类页 / 标签页 / `平台 × 类型` 交叉页（如 `/c/software?platform=mac`） | 吃长尾 |
| 结构化数据 | SoftwareApplication / Article / BreadcrumbList / FAQPage | 富摘要 |
| sitemap | 分片（每 5000 条一个），含 `lastmod` | 快速收录 |
| URL | 全小写、英文 slug、无参数污染（筛选参数 `noindex,follow`） | 避免重复内容 |
| 更新信号 | `/updates` + RSS + 详情页"更新于" | 抓取频率 |
| 性能 | Core Web Vitals 达标（见 02 文档性能预算） | 排名因子 |

**明确不做**：关键词堆砌、隐藏文字、批量生成伪原创、买外链。

## 六、可访问性与响应式硬要求

| 项 | 要求 |
|---|---|
| 断点 | 375 / 768 / 1024 / 1440，**375 下零横向滚动** |
| 触控 | 所有可点元素 ≥ 44×44px，间距 ≥ 8px |
| 键盘 | 全站 Tab 可达，`:focus-visible` 有 2px accent 描边，不可移除 |
| 对比度 | 正文 ≥ 4.5:1，大字 ≥ 3:1 |
| 图标 | 一律 Lucide SVG，**禁止 emoji 当图标** |
| 动效 | 尊重 `prefers-reduced-motion`；单次入场编排，不做逐块 fade-in |
| 语义 | 一个页面一个 `<h1>`；列表用 `<ul>`；下载按钮用 `<a>` 不用 `<div onclick>` |
| 图片 | 全部带 `alt`（封面图 `alt` = 资源标题）；`width/height` 必填防 CLS |
