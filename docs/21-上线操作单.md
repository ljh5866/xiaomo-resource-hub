## 第 0 步 · 放行端口（先做，否则后面白忙）

轻量控制台 → 服务器详情 → **防火墙** → 添加规则：

| 协议 | 端口 | 用途 |
|---|---|---|
| TCP | 22 | SSH（已通） |
| TCP | 80 | HTTP + 证书验证（**必须**） |
| TCP | 443 | HTTPS |

放行后本地验证：

```bash
# Windows PowerShell
foreach ($p in 80,443) { Test-NetConnection 43.103.48.5 -Port $p }
```

## 第 1.5 步 · SSH 登录（阿里云 Ubuntu 镜像默认用户是 admin，不是 root）

阿里云 Ubuntu 镜像默认禁用 root 密码登录、也关掉了密码认证，所以 ssh root@IP 一定报
Permission denied (publickey)。正确姿势是先用 **admin** 登录，再 sudo。

如果连 admin 也进不去（提示 publickey），在控制台 **远程连接（Workbench）** 里执行：

``bash
# 打开密码登录
sudo sed -i 's/^PasswordAuthentication no/PasswordAuthentication yes/' /etc/ssh/sshd_config
sudo sshd -t && sudo systemctl restart ssh
sudo sshd -T | grep -E '^(passwordauthentication|permitrootlogin)'

# 给 admin 设一个本地 SSH 要用的密码
sudo passwd admin
``

然后本地：

``powershell
ssh admin@43.103.48.5
scp deploy/bootstrap-ubuntu.sh admin@43.103.48.5:/tmp/
# 服务器上
sudo bash /tmp/bootstrap-ubuntu.sh
``

> 想直接用 root 也可以：`sudo passwd root` 设密码即可（`PermitRootLogin yes` 已经是开的）。
> 但更推荐 admin + sudo，出事故时少一分风险。

## 第 3 步 · 拉代码 + 一键安装

```bash
# 直接 clone 到目标目录（不要先建目录再 git clone ... .，会报"目录非空"）
sudo git clone https://github.com/ljh5866/xiaomo-resource-hub.git /var/www/xiaomo
sudo chown -R admin:admin /var/www/xiaomo
cd /var/www/xiaomo && ls

# 一条命令：写 .env（随机 AUTH_SECRET）→ 装依赖 → 迁移 → 建管理员
#          → 构建 → 装 systemd → 启服务 → 配 Caddy → 本地 + HTTPS 健康检查
sudo DOMAIN=ttals.com \
     ADMIN_EMAIL=你的邮箱 \
     ADMIN_PASS='强密码' \
     bash deploy/install.sh
```

脚本幂等：`.env` 已存在不覆盖、账号已存在只更新密码，可重复跑。

## 第 4 步 · 起服务 + 反代

```bash
cp deploy/xiaomo.service /etc/systemd/system/
cp deploy/xiaomo-maintenance.service /etc/systemd/system/
cp deploy/xiaomo-maintenance.timer /etc/systemd/system/

systemctl status xiaomo --no-pager | head -5

```

看到 `{"ok":true,...}` 说明服务本身没问题，接下来只管反代。

反代二选一：

```bash
# ttals.com 已经解析到本机，直接用生产配置

```

```bash
systemctl reload caddy

```

1. 阿里云 DNS → 添加 A 记录：`@` 与 `www` 都指向 `43.103.48.5`，TTL 600

3. 服务器上：


## 附：常见卡点对照表

| 现象 | 原因 | 处理 |
|---|---|---|
| `curl http://IP` 一直转圈 | 控制台防火墙没放 80 | 放行 TCP 80 |
| Caddy 日志 `tls: no certificate` | 域名解析还没生效，或 80 被封 | `nslookup` 确认解析；确认 80 放行 |
| 页面 502 | 服务没起来 | `systemctl status xiaomo`；`journalctl -u xiaomo -n 50` |
| 上传封面报 500 | `data/uploads` 权限不对 | `chown -R www-data:www-data /var/www/xiaomo/data` |
| 构建到一半 `Killed` | 内存不够 | `free -h`；2G 机型应正常，否则加 swap |
| 后台登录一直"邮箱或密码不对" | 账号没建 / 密码错 | `pnpm user:add 邮箱 密码 --admin` 重建 |
