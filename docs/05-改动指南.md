# 05 · 改动指南（改哪儿、多贵、别碰什么）

> 写给"以后会改很多次"的我们。目标是：**80% 的改动只碰一个文件。**
> 更新：2026-11-03

---

## 一、改动成本地图

| 你想改 | 改哪里 | 成本 | 会不会伤到别处 |
|---|---|---|---|
| 站点名 / 标语 / 导航 / 页脚 | `src/content/site.ts` | 1 分钟 | 不会 |
| 首页 Hero 文案、热搜词 | `src/content/site.ts` → `hero` | 1 分钟 | 不会 |
| 区块标题（本周精选 / 最新收录…） | `src/content/site.ts` → `sections` | 1 分钟 | 不会 |
| 搜索框占位文案 | `src/content/site.ts` → `search` | 1 分钟 | 不会 |
| 配色 / 字阶 / 圆角 / 动效 | `src/app/globals.css` 的 `:root` 与 `@theme inline` | 5 分钟 | 会全局生效（这是好事），改完看 `/styleguide` |
| 单个组件形态（按钮、卡片、标签） | 对应 `src/components/**` 单文件 | 10 分钟 | 只影响用到它的地方 |
| 新增一个页面 | `src/app/<route>/page.tsx` | 30 分钟 | 不会 |
| 新增一个字段（如"作者"） | `schema.ts` → `db:push` → 详情页 `<Field>` | 20 分钟 | 需要重跑迁移 |
| 改数据模型（如拆分"资源版本"） | `schema.ts` + `queries.ts` + 相关页面 | 半天 | 需要迁移脚本 |
| 换搜索实现 | `src/lib/search/index.ts` 一个文件（fts / like 两个分支已就位） | 半小时 | 调用方零改动 |
| 换数据库（SQLite → Postgres） | `src/db/client.ts` + `queries.ts` 的 SQL 方言 | 1–2 天 | 中 |
| 换框架 / 加 CMS | — | 一周+ | 高，先别想 |

## 二、三条"改起来便宜"的设计，请保持

### 1. 文案在配置里，不在页面里

```ts
// src/content/site.ts
export const site = {
  name: "小莫资源网",
  hero: { titleLines: ["找资源，", "别再翻十个网盘。"], ... },
  sections: { featured: { title: "本周精选" }, ... },
};
```

页面只读 `site.hero.titleLines`。**新页面不要硬编码标题**，否则第三次改文案时会漏两处。

### 2. 颜色在变量里，不在组件里

```css
/* globals.css */
:root { --accent: #d3a94f; }
@theme inline { --color-accent: var(--accent); }
```

组件写 `text-accent`、`border-line`，不写 `#d3a94f`。
→ 想换主色，改一行；想看效果，开 `/styleguide`。

### 3. 搜索有适配层

所有地方调 `search(q, opts)`（`src/lib/search/index.ts`），不直接碰 SQL。

- 当前：FTS5 + 2-gram 切词（`src/lib/search/tokenize.ts`），bm25 排序，标题列权重 8:1
- 兜底：索引为空或 0 命中时自动回落 SQL LIKE
- 改了切词规则？跑 `pnpm db:reindex` 重建索引
- 想换成 Meilisearch：在 `index.ts` 的 `SEARCH_MODE` 加一个分支，页面零改动

## 四、别碰的东西（碰了要重来）

| 别碰 | 为什么 |
|---|---|
| `src/db/client.ts` 换成 better-sqlite3 | Node 24 + Next 16 下会 `exit 134`（见 04 文档） |
| 组件里写死颜色 / 字号 | 主题切换立刻破功 |
| 把筛选状态放进组件 state | 链接不可分享、后退键失效、SEO 抓不到 |
| 在没有 `revalidate` 的页面里读 DB | 每次请求都查库，白烧 CPU |
| 直接改 `data/app.db` | 会被下次 `db:seed` 覆盖；改 `seed.ts` |
| 删掉 `loading.tsx` | 流式渲染会白屏闪烁 |
| `outline: none` | 键盘用户直接失去焦点可见性 |

## 五、想改设计方向时怎么做

不是"改个色"，而是三件事一起改，否则会变成四不像：

1. **底色 + 一个强调色**（`globals.css`）
2. **标题字族**（`--font-serif`）——换宋体/黑体/衬线是气质级改动
3. **一个标志性结构**（现在资源卡的"编号条 + 直角描边"就是它）

改完在 `/styleguide` 自检，再跑一遍截图。**只改一项，通常是"感觉变了但说不出哪里怪"的来源。**
